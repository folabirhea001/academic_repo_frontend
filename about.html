About the Project

Design and Implementation of an Artificial Intelligence Enabled Web-Based Academic Resources Repository.

Project Overview

This platform is designed to help students access lecture notes, textbooks, tutorials, and past examination questions through a centralized academic repository. It uses Artificial Intelligence to recommend relevant resources based on a student's academic level, search history, and self-test performance.

Core Features

  • Advanced search for academic resources.
  • AI-powered personalized recommendations.
  • Explainable AI (XAI) showing why resources are recommended.
  • Self-test quizzes and performance tracking.
  • Admin dashboard for uploading and managing resources.

Benefits to Students

Students can easily locate study materials, identify areas of weakness, practice with quizzes, and receive recommendations that improve academic performance and study efficiency.

Technology Stack

  • HTML5
  • CSS3
  • Bootstrap 5
  • JavaScript
  • PHP (Backend)
  • MySQL Database
  • Python AI Engine
  • Machine Learning Algorithms
